🌍 Travel Website

A fully responsive Travel Website built using HTML, CSS, and Bootstrap. The project showcases modern UI design, smooth layout structure, and mobile-first responsiveness. It includes destination sections, banners, packages, testimonials, and a clean navigation flow suitable for travel agencies or tourism platforms.

⭐ Features

Fully responsive design using Bootstrap grid

Clean and modern UI layout

Smooth navigation and scrolling experience

Destination highlights & travel package sections

Hero banner with call-to-action

Organized code structure using reusable components

🛠️ Tech Stack

HTML5

CSS3

Bootstrap 5
